# 限制类型 → 配料关键词 → 判定规则

判定任何餐品前先读这份表。

## 使用方式

1. 先按**名称粗筛**：餐品名和 `tags` 里命中关键词的，进候选池。
2. 候选池逐个调 `query-meal-detail`，读 `modification.items[].values[].name`。
3. 配料表里命中限制的，落到 ⚠️ 或 ⛔；一个都没命中的，落 ✅。
4. 配料表为空（`supportModify=false`）或该餐品不在候选池的，用名称判断并标注「配料信息有限」。

**名称判断的可信度低于配料判断。** 名称里看不出配料时，不要说「可以放心吃」。

**名称陷阱（实测）**：`521953 龙焰芝士棒鸡腿堡` 名称含「芝士」，
配料表却只有辣椒黄油风味酱与切块生菜，**没有吉士**。
`1440 麦辣鸡腿汉堡` 与 `1450 麦香鸡` 也都只有酱 + 生菜，**不含吉士**。

→ **判定一律以 `modification` 为准，不得凭菜名推断。**

**code 陷阱（实测）**：`1406 板烧鸡腿堡` 出现在菜单列表里，
但详情接口返回 60001，取不到配料。这类情况判为「配料信息有限」，
标注需现场确认，不得凭名称给出 ⛔ 或 ⚠️ 的确定性结论。


## 二、限制类型判定表

### 1. 牛肉忌口 / 清真饮食

**命中关键词**：牛、牛肉、培根（培根牛肉出品）、安格斯、巨无霸类牛肉堡
**主料判断**：名称含「牛堡」「牛肉」「巨无霸」「安格斯」「培根」的，牛肉是主料，**特调无法去除**，判 ⛔。

巨无霸的配料表含「巨无霸酱」，但**饼体本身是牛肉**，去掉酱不等于去掉牛肉。
这一点必须说清，否则用户会误以为「去酱就能吃」。

**话术**：
> ⛔ 巨无霸、培根安格斯厚牛堡等：主料为牛肉，无法通过特调去除。
> 如果你需要完全避开牛肉，这道菜不适用。

**可替代方向**：用 `list-nutrition-foods` 找非牛肉高蛋白项，如麦香鸡（15g 蛋白）、麦乐鸡（12g）、
那么大鸡排（24g 蛋白）、鸡腿堡。仍需现场确认是否含牛肉成分（共用油锅风险）。

### 2. 猪肉忌口 / 清真饮食

**命中关键词**：猪、培根、火腿、脆鸡（部分含猪骨提取）、猪柳麦满分
**判定**：菜单里明确含「猪」的品项，名称即可判断。培根、火腿扒麦满分含猪。

**重要提示**：麦当劳中国门店的猪肉来源与清真要求需现场核实。
本 Skill **不作清真认证**，只能告诉你菜单上标了什么。
涉及宗教饮食时，必须提示用户向门店确认。

### 3. 乳制品不耐受 / 乳糖不耐 / 牛奶过敏

**命中关键词**：吉士、奶油球、巨无霸酱、热朱古力、奶昔、纯牛奶、燕麦奶
**判定**：
- 单品汉堡：配料表有「吉士」→ ⚠️ 去掉吉士可解。
- 巨无霸酱：含乳成分，且去掉吉士后酱仍在 → 提示两道都要处理。
- 饮品：换「无糖可口可乐」「纯悦」「苹果片」「100% 苹果汁」「玉米杯」。
- 奶昔类（香草/草莓风味奶昔）无 `supportModify` → ⛔。

**话术**：
> ⚠️ 巨无霸 ¥25.5：去掉「吉士」可避开乳制品；「巨无霸酱」含乳成分，建议同时去掉。

**MCP 边界**：`supportModify=false` 的品项（如部分奶昔）无法确认乳成分，标注需现场确认。

### 4. 蛋忌口

**命中关键词**：猪柳蛋麦满分、火腿扒麦满分、麦香鱼（可能含蛋）、部分酱料
**判定**：名称含「蛋」的直接命中。巨无霸酱可能含蛋，标注为需确认。

### 5. 素食（蛋奶素 / 纯素）

**命中关键词**：所有肉类、鸡肉、鱼肉、蛋、奶
**判定难度**：这是最难的类别，因为**麦当劳几乎没有明确的素食标识**。

MCP 菜单返回中，少数餐品 `tags` 含「100%纯牛肉」「纯牛奶」这类描述性标签，
但**没有素食标识字段**。

**判定规则**：
- 名称含肉、鱼、蛋、奶 → ⛔ 建议避开
- 蔬菜类（玉米杯、苹果片）→ ✅ 可放心吃
- 麦旋风类（ Dairy 冰淇淋基底）→ 标注需现场确认，倾向 ⛔
- 果昔类：需确认基底是否含乳

**必须加的声明**：
> 麦当劳菜单接口未提供素食标识。以上依据名称与配料表推断，
> 实际是否含动物性配料需向门店确认。

**不要**把这个 Skill 宣传成「能帮你找到纯素餐」——数据支撑不了这个承诺。

### 6. 控钠（高血压医嘱）

**判定**：用 `list-nutrition-foods` 的 `sodium`（毫克）。
实测数据区间参考：中薯条 165mg、小杯玉米杯 1mg、大杯玉米杯 2mg、纯牛奶 73mg，
而多数汉堡在 480–1370mg 区间（培根安格斯厚牛堡 1037mg、芝士双层安格斯厚牛堡 1373mg）。

**推荐**：玉米杯、小杯玉米杯、苹果片、浓缩咖啡（3mg）、
无糖可口可乐（0mg）、纯悦（0mg）。

**边界声明**：门店实际做法与钠含量会有波动，数据仅供选择参考。

### 7. 控热量

**判定**：用 `energyKcal`。低热量选项：
纯悦 0、大杯玉米杯 87、浓缩咖啡 13、大杯鲜萃咖啡 13、中杯怡泉+C 110、
麦辣鸡翅2块 224、麦香鸡 369。

**必须加的声明**：
> 营养数据来自官方餐品营养库，含酒精饮品与实际做法差异，
> 不构成营养或医疗建议。具体摄入请遵医嘱。

### 8. 控糖 / 糖尿病

**推荐**：无糖可口可乐（0 能量）、无糖雪碧、大杯鲜萃咖啡（13kcal）、
锡兰红茶（2kcal）、纯牛奶（129kcal，含乳糖）。

**注意**：无糖可乐中杯含碳水 1g、大杯 1g、雪碧中杯 36g，差异明显，看清再选。

## 三、无法判定的项（必须标注需确认）

以下信息 MCP 接口**不提供**，任何情况下都不要给出确定性结论：

| 项目 | 为什么查不到 |
|---|---|
| 花生、坚果、芝麻 | 无过敏原字段 |
| 麸质 / 小麦 | 无过敏原字段 |
| 甲壳类、贝类、鱼过敏 | 无过敏原字段，名称难判定 |
| 交叉污染（共用油锅/器具） | 接口无此数据 |
| 清真认证状态 | 接口无此数据 |
| 素食标识 | 接口无此数据 |
| 实际做法与配方差异 | 接口数据为标准值 |
| 门店当日食材批次 | 接口无此数据 |

**标准表述**：
> ⚠️ 该项麦当劳菜单接口未提供数据，需向门店店员现场核实。

涉及**严重过敏**时，先给安全建议，再谈菜单：

> 如果你有严重过敏史或曾出现过敏性休克，请不要依赖本 Skill 的结论自行下单，
> 建议直接联系门店确认，或选择其他就餐方式。

## 四、判定优先级

当多个限制同时存在时：

1. **主料命中 → 直接 ⛔**，不看特调。
2. **配料命中且可去 → ⚠️**，列出要删的每一项。
3. **配料表无法覆盖的限制 → 无论档位，末尾加需确认声明。**
4. **不因为「用户想吃」而放宽判定。** 想吃就说明代价，不隐瞒。
